📚 Fluxo OAuth2 Authorization Code

  1. Authorization Request: Cliente redireciona usuário para Authorization Server
  2. User Authentication: Usuário faz login com suas credenciais
  3. Consent Screen: Usuário autoriza os escopos solicitados
  4. Authorization Grant: Servidor gera Authorization Code
  5. Token Request: Código trocado por tokens com sucesso ✅
  6. Token Request: Erro na troca do código por tokens ❌
  7. Access Granted: Cliente pode usar tokens para acessar recursos protegidos
