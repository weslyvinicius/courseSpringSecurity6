📚 O que aconteceu (Client Credentials Grant):

  1. Requisição Direta: Sua aplicação enviou credenciais para /oauth2/token
  2. Autenticação: Authorization Server validou client_id e client_secret
  3. Token Gerado: Servidor retornou access_token imediatamente
  4. Pronto para Usar: Token pode ser usado em APIs protegidas
  5. Erro: Falha na validação das credenciais
⚠️ Importante:
  • Client Credentials Grant não envolve usuários - apenas aplicações
  • O token representa a identidade da aplicação, não de um usuário
  • Ideal para comunicação entre serviços (machine-to-machine)
  • Nunca exponha o client_secret em aplicações client-side!
