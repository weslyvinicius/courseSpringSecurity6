Como Funciona o Refresh Token
1
Configurar Cliente: Selecione o cliente OAuth2 que foi usado na autorização original
2
Fornecer Refresh Token: Cole o refresh token válido obtido anteriormente
3
Solicitar Renovação: O sistema fará a requisição para o token endpoint
4
Receber Novos Tokens: Novos access token e refresh token serão gerados

⚠️ Pontos Importantes:

  • O refresh token deve ser válido e não expirado
  • O client ID e secret devem ser os mesmos da autorização original
  • O scope solicitado não pode ser maior que o original
  • Alguns servidores podem invalidar o refresh token anterior após o uso
