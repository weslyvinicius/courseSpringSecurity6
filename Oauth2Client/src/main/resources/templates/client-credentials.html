Como Funciona o Client Credentials
1
Configurar Cliente: Selecione o cliente OAuth2 configurado para client_credentials
2
Definir Escopos: Especifique os escopos que sua aplicação precisa acessar
3
Autenticar Aplicação: O sistema enviará as credenciais para o authorization server
4
Receber Token: Access token será gerado para acesso aos recursos

⚠️ Pontos Importantes:

  • Este fluxo é usado para comunicação server-to-server
  • Não há interação do usuário final neste processo
  • O client secret deve ser mantido seguro
  • Os escopos são específicos para a aplicação, não para usuários
  • Normalmente não são gerados refresh tokens neste fluxo
Casos de Uso do Client Credentials

APIs Backend

📊
