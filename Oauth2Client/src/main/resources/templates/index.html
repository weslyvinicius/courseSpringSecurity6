🔐 OAuth2 Client Credentials Demo

🤖 Client Credentials Grant

Este fluxo é usado para autenticação de aplicação para aplicação (machine-to-machine). Não envolve usuários finais - apenas as credenciais do cliente.

Casos de uso típicos: APIs que acessam outras APIs, serviços internos, jobs automatizados.

🚀 Obter Access Token

Deixe vazio para usar os scopes padrão do cliente

📋 Como funciona o Client Credentials Grant:

  1. Requisição Direta: Cliente envia credenciais diretamente para /oauth2/token
  2. Validação: Authorization Server valida client_id e client_secret
  3. Token Imediato: Se válido, retorna access_token imediatamente
  4. Uso do Token: Cliente usa o token para acessar APIs protegidas

🔗 Endpoint do Authorization Server:

POST http://localhost:8080/oauth2/token
Content-Type: application/x-www-form-urlencoded
Authorization: Basic [client_id:client_secret em Base64]

Body: grant_type=client_credentials&scope=read write
⚠️ Importante: Certifique-se de que seu Authorization Server esteja rodando na porta 8080!
