🔐 OAuth2 Client Demo

Teste do Fluxo Authorization Code

Esta aplicação demonstra o fluxo OAuth2 Authorization Code Grant com seu Authorization Server.

📋 Como funciona:

  1. Clique no botão "Fazer Login" abaixo
  2. Você será redirecionado para o Authorization Server (porta 8080)
  3. Faça login com: user / password
  4. Após o login, você será redirecionado de volta para esta aplicação
  5. Você verá o Authorization Code e a troca por tokens
🚀 Iniciar Fluxo OAuth2

🔧 Configurações atuais:

  • Client ID: my-client
  • Authorization Server: http://localhost:8080
  • Redirect URI: http://localhost:8081/callback
  • Scopes: openid profile
