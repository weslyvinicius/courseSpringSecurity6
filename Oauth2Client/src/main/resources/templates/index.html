Teste Completo do Fluxo Authorization Code

Selecione um cliente e um usuário para testar diferentes cenários de autorização OAuth2.

📱 Selecione o Cliente (Aplicação)

Cada cliente tem escopos diferentes que pode solicitar:

🌐 Web Application
web-app
openid profile email employee.read employee.write employee.delete report.read report.write report.delete admin
Aplicação web completa com acesso total. Pode solicitar todos os escopos disponíveis.
📱 Mobile App
mobile-app
openid profile employee.read report.read
Aplicação móvel com acesso limitado. Apenas leitura de dados.
📊 Dashboard
dashboard-app
openid profile employee.read employee.write report.read report.write
Dashboard gerencial. Pode ler e escrever, mas não deletar.
📈 Reports App
reports-app
openid profile report.read report.write
Aplicação específica para relatórios. Sem acesso a funcionários.
