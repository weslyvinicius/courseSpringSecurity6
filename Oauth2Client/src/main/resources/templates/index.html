Authorization Code Flow
Fluxo completo de autorização OAuth2 onde o usuário é redirecionado para o Authorization Server para autenticação e consentimento.
1
Configurar parâmetros do cliente OAuth2
2
Redirecionamento para Authorization Server
3
Receber Authorization Code no callback
4
Trocar código por Access Token

Refresh Token Flow
Renovação de Access Tokens usando Refresh Token sem necessidade de nova autenticação do usuário.
1
Configurar dados do cliente
2
Fornecer Refresh Token válido
3
Solicitar novo Access Token
4
Receber novos tokens
🔄 Iniciar Refresh Token Flow
Recursos Disponíveis
  • Fluxo Authorization Code completo com redirecionamento
  • Suporte a múltiplos clientes OAuth2 pré-configurados
  • Renovação automática de tokens com Refresh Token
  • Validação em tempo real de URLs e parâmetros
  • Decodificação automática de tokens JWT (ID Token)
  • Interface responsiva e intuitiva
  • Logs detalhados de todas as operações
